CAMPOS CALCULADOS (EJEMPLOS)

// % promotores menos % detractores NPS = (SUM(IIF([Puntuación]>=9,1,0)) - SUM(IIF([Puntuación]<=6,1,0))) / COUNT([ID Encuesta]) // Satisfacción promedio por ruta, ignorando filtros de vista (LOD) Satisfacción Prom. Ruta = { FIXED [Ruta] : AVG([Puntuación]) } // Semáforo de NPS Estado Ruta = IF [NPS] >= 30 THEN "Óptimo" ELSEIF [NPS] >= 10 THEN "Revisar" ELSE "Crítico" END

ENFOQUE

El NPS se calcula sobre la escala 0-10 estándar (promotores 9-10, detractores 0-6) para que sea comparable con benchmarks del sector, no una escala inventada. Separé "quejas por categoría" de "NPS" a propósito — el NPS dice qué tan bien vas en general, pero no dice qué arreglar primero; el desglose por categoría sí. Los datos son sintéticos, generados para este caso — no proceden de ninguna aerolínea real.
