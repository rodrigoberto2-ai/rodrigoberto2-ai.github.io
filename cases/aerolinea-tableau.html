CAMPOS CALCULADOS (EJEMPLOS)

// Puntualidad — llegada dentro de 15 min del horario OTP = SUM(IIF([Hora Real Llegada] <= [Hora Programada Llegada] + 15, 1, 0)) / COUNT([ID Vuelo]) // Turnaround promedio por aeropuerto, ignorando filtros de vista (LOD) Turnaround Prom. Aeropuerto = { FIXED [Aeropuerto] : AVG([Tiempo en Tierra]) } // Semáforo de la ruta Estado Ruta = IF [OTP] >= 0.85 THEN "Óptimo" ELSEIF [OTP] >= 0.75 THEN "Revisar" ELSE "Crítico" END

ENFOQUE

El turnaround en tierra es la métrica que más se presta a confusión si se mide mal: un promedio simple por vuelo se distorsiona por outliers (mantenimiento no programado, meteorología). Por eso usé una LOD expression fija por aeropuerto — da una base estable para comparar hubs entre sí, sin que el filtro de fecha o ruta la altere fila por fila. El OTP se define con margen de 15 minutos porque es el estándar habitual del sector, no una llegada exacta al minuto. Los datos son sintéticos, generados para este caso — no proceden de ninguna aerolínea real.
