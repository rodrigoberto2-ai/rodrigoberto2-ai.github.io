CAMPOS CALCULADOS (EJEMPLOS)

// Ingreso por asiento-kilómetro disponible RASK = SUM([Ingreso Total]) / SUM([Asientos Disponibles] * [Distancia Km]) // Ingreso promedio por ruta, ignorando filtros de vista (LOD) Ingreso Prom. Ruta = { FIXED [Ruta] : AVG([Ingreso Total]) } // Semáforo de margen Estado Ruta = IF [Margen] >= 0.20 THEN "Óptimo" ELSEIF [Margen] >= 0.10 THEN "Revisar" ELSE "Crítico" END

ENFOQUE

RASK en vez de ingreso bruto por ruta, porque una ruta puede facturar más solo por tener más asientos o más distancia — RASK normaliza eso y permite comparar rutas de tamaños distintos de forma justa. El margen usa un costo estimado por ruta (combustible, tasas aeroportuarias, tripulación) para no confundir "ruta con más ingreso" con "ruta más rentable" — son cosas distintas. Los datos son sintéticos, generados para este caso — no proceden de ninguna aerolínea real.
