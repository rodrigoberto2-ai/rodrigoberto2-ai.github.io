CAMPOS CALCULADOS (EJEMPLOS)

// % del tiempo que la flota está operativa Disponibilidad = 1 - (SUM([Horas en Tierra por Mant.]) / SUM([Horas Totales Periodo])) // Horas de vuelo entre fallos no programados MTBF = SUM([Horas de Vuelo]) / SUM(IIF([Tipo Evento]="No programado",1,0)) // Costo promedio por aeronave, ignorando filtros de vista (LOD) Costo Prom. Aeronave = { FIXED [Aeronave] : AVG([Costo Mantenimiento]) }

ENFOQUE

La disponibilidad y el MTBF cuentan historias distintas: disponibilidad mide cuánto tiempo la flota puede volar; MTBF mide cuán seguido falla algo sin avisar. Una aeronave puede tener alta disponibilidad pero MTBF bajo (fallos frecuentes pero rápidos de resolver) — separarlas evita esconder un problema real detrás de un solo número agregado. Los datos son sintéticos, generados para este caso — no proceden de ninguna aerolínea real.
