Modelo semántico y medidas DAX con inteligencia de tiempo.

MODELO EN ESTRELLA

MEDIDAS DAX (EJEMPLOS)

Ventas YTD = TOTALYTD(SUM(Ventas[Importe]), Dim_Fecha[Fecha])
% Objetivo = DIVIDE([Ventas YTD], [Objetivo Anual])
Ticket Medio = DIVIDE([Ventas YTD], DISTINCTCOUNT(Ventas[PedidoID]))
Var. vs Año Anterior = DIVIDE([Ventas YTD] − CALCULATE([Ventas YTD], SAMEPERIODLASTYEAR(Dim_Fecha[Fecha])), CALCULATE([Ventas YTD], SAMEPERIODLASTYEAR(Dim_Fecha[Fecha])))

ENFOQUE

El ranking usa formato condicional con barra de progreso por fila (medida de % hacia objetivo), y las medidas de tiempo (YTD, año anterior) están separadas de las medidas base para poder reutilizarlas en la página de Productos y Clientes sin duplicar lógica. Los datos son sintéticos, generados para este caso — no proceden de ningún cliente real.
